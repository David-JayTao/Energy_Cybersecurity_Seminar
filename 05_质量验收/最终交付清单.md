# 最终交付清单

## 正式使用文件

| 类别 | 数量 / 内容 |
|---|---|
| 项目入口 | README、项目总览与课程核对、老师讨论提纲 |
| 独立成员包 | 3套，每套10页逐页成品、连续讲稿、逐页时间、知识准备、书目、交接卡 |
| 页面 | 30页，每页完整八项内容 |

| 图表主题 | 31组：每页1组，加中国安全分区补充图 |

全组中央估计39.37分钟，计算单位与语速假设可追溯。实际演练速度可能不同，已附排练调整说明。

## 文件格式和交付范围

正式文档为UTF-8 Markdown，图表为可插入、可编辑素材。没有创建最终PPT文件，也没有另建在线幻灯片。Word为任务书可选项，本次未额外生成。

原始课程PPT与Excel保留在项目上级目录，未改写。`sources/`中的代码用于复现材料、渲染和检查，不是必须由同学继续完成的工作。

## 使用顺序

先读README定位本人目录，阅读本人完整稿，再用逐页第3项制作页面并插入图表。三人合练时只保留P01总开场、P10与P20交接、P30总收尾。老师讨论使用根目录提纲。问答准备使用全组题库与本人知识材料。

研究截止2026-11-03。证据限制已逐条记录，尤其是IEC摘要边界、事件未公开细节及AI结果未复现，不应在制作PPT时删除这些限定。
