# 第二部分制作交接与排练卡

2026-11-10新版；刘酝潇，P11–P20。最终PPT由本人制作，研究、讲稿与图表已配套。

## 制作顺序

1. 使用[逐页内容](PPT逐页完整内容.md)每页第2项的最终上屏文案，第4项讲稿放备注。不要整段复制到屏幕。
2. 同编号PNG为1600×900，直接插入；SVG用于缩放和修改。P13、P15应大幅展示，整幅图已带标题时不要重复标题。保留来源和“教学示意”等限定。
3. P13先讲系统角色，再指控制和反馈方向；P14说明身份与操作能力；P15上下比较，再讲备用条件；P16分清中断与恢复受阻。
4. P18保留运营方主语，P19比较机制，P20提出两个具体问题。建议16:9，正文至少22磅，脚注至少12磅；复杂图不要缩成小角图。

## 理解与排练

先读[知识讲透与答辩](第二部分_知识讲透与答辩准备.md)，再读[案例研究](典型案例研究.md)，最后连续讲[逐字稿](完整演讲逐字稿.md)。正式讲稿3381汉字、3386口播单位，中央估算803秒，即13.38分钟，详见[时间表](各页讲解时间表.md)。这是估算，未进行真人试讲。

排练记录真实用时和卡住的概念。可用自己的表达，但保留四项限定：客户不是人数；功能正常不等于操作获授权；示意图不是现场拓扑；停运不是设备被直接操纵的证据。

超过14分钟先压缩P11、P19归纳，不删P13–P16核心机制；超过15分钟应调整后再计时。明显不足12分钟时检查是否跳过现场终端、唯一有效供电路径及恢复差异，不靠额外停顿或未核实案例凑时间。课程允许10–15分钟合理波动。

## 维护与复现

只在需要重生成且已备份手工修改时，在本目录执行：

```powershell
python -X utf8 build_part2.py
python -X utf8 draw_part2.py
python -X utf8 render_part2.py
python -X utf8 validate_part2.py
```

内容与绘图生成依赖Python标准库；渲染需要Pillow和Windows Chrome，可用PART2_CHROME指定路径。Mermaid校验只读取共享运行库，浏览器临时配置在系统临时目录。生成脚本只写本人目录；修改讲稿应同步源数据再生成，避免计时和连续讲稿不一致。不要运行全组旧生成器覆盖新版。
