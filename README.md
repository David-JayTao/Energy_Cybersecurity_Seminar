## 图表怎么用

共32组图：原有30页各一组、1组中国分区补充图，另新增1组第一部分聚焦版思维脉络导图。每组均提供SVG、1600×900 PNG和Mermaid源码；另有9份CSV表格。**这些是素材，不是最终幻灯片。**PNG可直接插入；SVG可缩放；Mermaid供编辑结构；CSV便于重排。书目和讲稿不应全部放到页面上。

## 仓库维护说明

- 三位成员分别维护自己的目录；共同书目、证据及答辩材料集中在 `04_全组资料/`。
- 可在仓库根目录执行 `python -X utf8 sources/audit.py` 检查页面、讲稿、图表与本地链接是否完整。
- 图表重渲染脚本使用 Windows、Google Chrome 和 Pillow；现成 PNG 已包含在仓库中。浏览器缓存、Python 缓存及本地环境文件不纳入版本控制。
- `05_质量验收/` 保留研究交付时的检查记录和图表预览；其中路径及文件清单属于当时的本机快照。
- `sources/` 中的第三方文献、网页摘录和 Mermaid 库保留其原有权利归属，不因收录于本仓库而改变许可。引用时请使用核心文献表中的原始出处。
