# 术语表与概念解释

正文首次出现的基础概念以中文和英文全称配对；本表集中解释缩写，三位成员均应掌握前12项。[主要依据R01、R12–R14、R18、R21–R24]

| 术语 | 英文全称 | 本项目中的准确含义 / 易错点 |
|---|---|---|
| IT | Information Technology | 信息技术，侧重业务信息处理；不是“所有Windows电脑” |
| OT | Operational Technology | 运行技术，监视或控制物理过程；范围大于PLC |
| ICS | Industrial Control Systems | 工业控制系统，OT中的重要类别 |
| SCADA | Supervisory Control and Data Acquisition | 监控与数据采集，常用于分散设施 |
| HMI | Human–Machine Interface | 人机界面，显示与交互功能；不等于全部控制系统 |
| PLC | Programmable Logic Controller | 可编程逻辑控制器，处理现场控制逻辑 |
| RTU | Remote Terminal Unit | 远程终端单元，远方采集与控制；可与PLC功能重叠 |
| IED | Intelligent Electronic Device | 智能电子设备，电力场景可含保护与测控装置 |
| DER | Distributed Energy Resources | 分布式能源资源，可含分布式发电、储能及灵活负荷 |
| EMS | Energy Management System | 能源管理系统；本材料储能场景指调度管理功能 |
| BMS | Battery Management System | 电池管理系统，监测电池状态并提供相关保护 |
| IIoT | Industrial Internet of Things | 工业物联网，扩展设备感知和连接 |
| VPN | Virtual Private Network | 虚拟专用网络；加密通道不等于可信操作者 |
| MFA | Multi-Factor Authentication | 多因素认证；不同因素提高身份核验强度，不保证会话绝对安全 |
| DMZ | Demilitarized Zone | 网络隔离缓冲区；通用工业模型不能替代中国电力专用隔离要求 |
| RBAC | Role-Based Access Control | 基于角色的访问控制；角色应匹配最小业务权限 |
| IDS | Intrusion Detection System | 入侵检测系统，发现可疑活动；检测不等于阻断成功 |
| SOC | Security Operations Center | 安全运营中心，组织监测、研判与响应 |
| 零信任 | Zero Trust | 不因处于内部网络就默认可信，按身份、对象和上下文授权；须适配OT时限与可用性 |
| 联锁 | Interlock | 按规定条件限制操作的机制，是否独立和覆盖哪些危险须具体分析 |
| 继电保护 | Protective Relaying | 根据电气故障等条件实现保护动作；不能认为防住所有恶意调度 |
| 韧性 | Resilience | 承受、适应并恢复功能的能力，需降级与恢复证据 |
| ML | Machine Learning | 机器学习，从数据形成模型，不专指深度神经网络 |
| DNN | Deep Neural Network | 深度神经网络；论文中的具体结构和数据决定结果 |
| LSTM | Long Short-Term Memory | 长短期记忆网络，可建模序列关系 |
| SVM | Support Vector Machine | 支持向量机；单类SVM也是机器学习，不是人工规则 |
| FSL | Few-Shot Learning | 少样本学习，减少目标任务所需标注样本不等于全部成本归零 |
| LLM | Large Language Model | 大语言模型，擅长文本生成和整理；流畅不等于事实正确 |
| SWaT | Secure Water Treatment | 安全水处理试验台；本材料引用其论文，不将它当作电网数据 |
| 精确率 | Precision = TP/(TP+FP) | 被报为正例的记录中有多少为真；高值不能保证不漏报 |
| 召回率 | Recall = TP/(TP+FN) | 真实正例中被检出的比例；需说明正例与计数单位 |
| F1 | F1 score = 2PR/(P+R) | 精确率与召回率的调和平均；不是完整安全效益指标 |
| 误报 / 漏报 | False Positive / False Negative | 把正常报为异常 / 未发现真实异常 |
| 分布漂移 | Distribution Shift / Drift | 部署数据关系随工况、设备或时间变化，可能影响模型 |
| 提示注入 | Prompt Injection | 不可信输入诱导模型偏离预期任务；工具权限可放大影响 |
| 数据泄漏（评测） | Data Leakage | 测试信息进入训练或选择流程，使实验分数偏乐观 |

## 十分钟共同复习

先看P03架构，指认测量与控制方向；再看P14和P18，分别说清谁导致控制或停运变化；最后看P29，指出每个案例失效环节由哪一层措施应对。每人用一句话解释“已知事实、研究分析、本组推论”的区别。

答辩时先给结论，再说明证据边界。如果老师问到本项目没有核实的设备型号、具体漏洞或损失金额，应明确说“公开材料不足以支持该细节”，回到已核验的机制，不能现场编造。
